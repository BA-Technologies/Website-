# BA Technologies Website
Official website of **BA Technologies Ltd** (RC 9364300), a Lagos-based private technology and holding company focused on acquisitions, investment, and technology ventures across Nigeria and Africa.

🌐 **Live site:** https://batechnologies.netlify.app

## About

This repository contains the source code for the BA Technologies company website. Any change pushed to the `main` branch is deployed automatically through Netlify.
